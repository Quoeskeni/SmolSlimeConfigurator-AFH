Codex status / инструкция как отвечать
======================================

Пиши следующий ответ в репозиторий prompt в файл chat.txt или продолжай обычным сообщением здесь, если файл недоступен.
Если хочешь остановить такой файловый чат, удали chat.txt в prompt-репозитории, как ты и предлагал.

Что сделано в этом ходе:
- В SmolSlimeConfigurator-AFH добавлен документированный terminal console mode: `python SmolSlimeConfiguratorV9.py --console --port <COM/tty> [--raw]`.
- Smart GUI/console теперь явно рассчитаны на автоопределение Tracker/Receiver по COM-логу и вывод человеческой сводки вместо сырого спама.
- Сервер SlimeVR-Server-AFH пока не менял: по текущей задумке ресивер должен оставаться HID-совместимым, а пакеты до сервера должны чиниться в firmware receiver/tracker.

Что нужно прислать для следующей итерации, если пакетов всё ещё ноль:
1. Лог receiver после включения SlimeVR Server и подключения донгла по USB.
2. Лог tracker во время движения/пейринга.
3. Скрин/текст из SlimeVR Server: видит ли он HID dongle, появляются ли trackers.
4. Укажи, какой UF2 прошит: latest release из SlimeNRF-Firmware-CI или конкретный artifact.
